# 系统剪贴板

首次运行测试先执行 npm install --ignore-scripts，安装固定的开发测试依赖；这些依赖不进入运行包。

版本 0.1.1：显示、筛选和复制图片历史，按宿主返回的 kind 区分图片与普通文本；旧宿主未提供 kind 时兼容已有 PNG/JPEG/BMP 数据 URL 记录。普通文本即使内容像图片数据 URL，也不会在新宿主下误判为图片。

图片历史采集需要同步升级宿主：旧宿主只读取文本，单独更新插件不会补回从未采集过的图片。新采集仅处理启用新宿主后复制的图片；PNG 数据 URL 单条最多 4 MiB，图片历史总内容上限 32 MiB，像素数不超过 1600 万；超限图片不入库，不影响文本历史。数据存于本机，插件不申请网络权限。

执行 npm test、npm pack 后，在宿主“插件中心 → 开发者 → 安装插件包（.zip / .tgz）”安装，关闭重开。

系统剪贴板：查看历史记录、复制与删除。

源码版本：0.1.1；适用于 MyTools，不能作为独立网页调用宿主能力。

## 安装

在 MyTools 插件管理的 npm 安装入口输入 `@mytools-all/mytools-clipboard@0.1.1`。也可以下载本仓库，在开发者页面选择“安装本地目录”。

## 开发

直接编辑本目录的 HTML、JavaScript 和样式，无需依赖宿主源码或其他插件仓库。修改后重新安装本地目录。运行 `npm test` 检查包内契约和逻辑。插件 API 规范见 [mytools](https://github.com/mytools-all/mytools/tree/main/docs)。

## 权限

声明的宿主能力：clipboard.history、clipboard.write、clipboard.remove。目录和危险操作仍需用户授权。

## 许可

项目代码使用 MIT；随附的第三方代码遵循各自随附的许可证。

## MyTools 兼容范围

版本 0.1.2 声明支持 MyTools >=0.2.0 <0.3.0（0.2.x 稳定版），插件 API 为 v1。主程序超出范围时应更新插件或使用受支持的主程序版本。旧版主程序可能不识别此声明，请先升级到提供兼容检查的 MyTools。
